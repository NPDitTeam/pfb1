# Custom Fix Fields Module

## Description
โมดูลสำหรับแก้ไขปัญหาฟิลด์ที่ขาดหาย และปัญหา database schema

## Features
- ✅ เพิ่มฟิลด์ `c_date` ใน Sale Order
- ✅ เพิ่มฟิลด์ `custom_notes` ใน Invoice
- ✅ แก้ไขปัญหาการ create/write record
- ✅ รองรับ Odoo 14

## Installation
1. Copy module ลงในโฟลเดอร์ custom addons
2. Update Apps List ใน Odoo
3. ค้นหา "Custom Fix Fields" และติดตั้ง
4. Restart Odoo server

## Usage
Module นี้จะทำงานอัตโนมัติหลังจากติดตั้ง:
- เพิ่มฟิลด์ใหม่ใน Sale Order Form
- เพิ่มฟิลด์ใหม่ใน Invoice Form
