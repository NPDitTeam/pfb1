# แก้ปัญหา "หักซ้ำ" ขาด/ออกก่อนเวลา กับ การลา

## ปัญหา
กรณี **30/04/2026** (พนักงาน อรุณ หอมคง รหัส 0435):
- มีใบลา 15:00–17:00 (ลากิจไม่ได้รับค่าจ้าง) → หัก "ยอดหักจากการลา"
- สแกนออก 15:02 → ระบบมองเป็น "ออกก่อนเวลา / ขาด 1ชม 58นาที" → หัก "ยอดหักออกก่อนเวลา/ขาดงาน" อีกรอบ

ช่วงเวลาเดียวกัน (15:00–17:00) ถูกหัก **2 รอบ**

## สาเหตุ
ฝั่ง PHP (`calculate_lateness.php`) เดิม เมื่อเจอใบลาในวันนั้นจะ `continue` ข้ามทั้งวัน
แต่ในการ deploy จริงพฤติกรรมไม่ตรง ทำให้ยังคิด "ออกก่อนเวลา" ทับช่วงลา → หักซ้ำ
และหน้ารายงาน (`lateness_summary.php`) ไม่เคยตรวจใบลาเลย จึงโชว์ "ขาด" ทับวันลา

## วิธีแก้ (กฎใหม่)
**ตัดเฉพาะนาทีที่ทับซ้อนกับช่วงเวลาลา ออกจากการคิด สาย/ออกก่อนเวลา**
ครอบคลุม **ทุกใบลาที่อนุมัติ** ของวันนั้น

ตัวอย่าง:
- ลา 15:00–17:00 + ออก 15:02 → ออกก่อนเวลาทับช่วงลาเต็ม → คิดออกก่อนเวลา = 0 (หักแค่ "ลา")
- ลา 15:00–17:00 + ออก 14:30 → คิดออกก่อนเวลาเฉพาะ 14:30–15:00 = 30 นาที + หัก "ลา"
- ลาทั้งกะ → ข้ามการคิด สาย/ออกก่อนเวลา ทั้งวัน

### หักการลา = คิดเป็น "นาที" ตามจริง
`calculateLeaveDeduction()` เดิมปัดเศษชั่วโมงลาขึ้นเป็นชั่วโมงเต็ม (เช่น 37 นาที → 1 ชม.)
เปลี่ยนเป็นคิดเป็นนาทีตามจริง (37 นาที × ค่าจ้างต่อนาที) ให้สอดคล้องกับ สาย/ออกก่อนเวลา
- ลาทั้งกะ → ยังหักเต็มวัน (daily_rate) เหมือนเดิม

## ไฟล์ที่แก้ (ต้องอัปโหลดทับบนเซิร์ฟเวอร์ npdhrms.com)
> ไฟล์ทั้งสองนี้อยู่บน web root ของ https://npdhrms.com (ไม่ได้อยู่ในเครื่อง Odoo)
> โฟลเดอร์นี้เป็นแค่ที่เก็บเวอร์ชันที่แก้แล้ว — ต้องนำขึ้นไปแทนของจริง

1. `calculate_lateness.php`  → แทนที่ `https://npdhrms.com/calculate_lateness.php`
2. `lateness_summary.php`    → แทนที่ `https://npdhrms.com/lateness_summary.php`

**สิ่งที่เปลี่ยน:**
- เพิ่ม helper `getOverlapMinutes()`
- `calculate_lateness.php`: เปลี่ยน logic วันมีใบลา — ดึงทุกใบลา, ลาทั้งกะ→ข้ามทั้งวัน,
  ลาบางช่วง→ยังคิดสาย/ออกก่อนเวลาแต่หักลบนาทีที่ทับช่วงลา; วันมีใบลาแต่ไม่สแกน→ไม่นับขาด
- `lateness_summary.php`: ดึงช่วงลาของวันนั้นมาหักลบก่อนแสดง "สาย/ขาด"
  ถ้าถูกลาดูดซับหมด → แสดง "ลา (ช่วงเช้า/ช่วงบ่าย)" สีน้ำเงิน

## ฝั่ง Odoo
ตรรกะการคำนวณ **ไม่ต้องแก้** — โมดูล `employee_salary` รับค่าจาก PHP มาตรง ๆ

**สิ่งที่เพิ่มในรอบนี้ (ตารางแจกแจงการหักแบบละเอียด):**
- เพิ่ม model `payroll.deduction.line` + field `deduction_line_ids` บน `payroll.salary`
- ในแท็บ *คำนวณขาดลามาสาย* หัวข้อ "รายละเอียดการหัก (แจกแจงรายวัน)"
  เปลี่ยนจากข้อความล้วน → **ตาราง** คอลัมน์: วันที่ / วัน / ประเภท / รายละเอียด / เวลา / นาที / ยอดหัก
  (มีแถวรวมยอดหักท้ายตาราง)
- ต้องการเวลา (เข้า/ออกจริง, เวลากะ, ช่วงลา) → `calculate_lateness.php` ถูกเพิ่มเวลาลงใน
  `late_checkin_log` / `early_checkout_log` / `leave_log` แล้ว (debug)

> ⚠️ มี model + field + security + view ใหม่ → ต้อง **อัปเกรดโมดูล** `employee_salary`
> (`-u employee_salary` หรือผ่านเมนู Apps) เพื่อสร้างตารางในฐานข้อมูล
